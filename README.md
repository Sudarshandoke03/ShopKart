# ShopKart React Frontend

A responsive demo e-commerce frontend built with React, Vite, JavaScript and plain CSS.

## Features
- Home page with hero banner and popular products
- Product listing, search, category filter and sorting
- Product detail view
- Add to cart, quantity update and remove item
- Wishlist
- Demo login and signup
- Cart and wishlist persist in localStorage
- Responsive layout for mobile and desktop

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the `shopkart-frontend` folder in VS Code.
3. Open Terminal in that folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown by Vite (usually http://localhost:5173).

## Build
```bash
npm run build
```

## Important
This is a frontend learning/demo project. Login/signup is not connected to a real backend, payment is not real, product data is stored in a local JavaScript file, and product visuals use emoji placeholders. Do not enter real passwords or payment information.
